# MAGIC论文复现报告
## 一、复现概述
### 1.1 复现目标
本次复现针对USENIX Security 2024论文《MAGIC: Detecting Advanced Persistent Threats via Masked Graph Representation Learning》，目标是搭建符合论文要求的实验环境，完成批级检测场景下的核心数据集评估，验证模型的检测性能，复现论文中的核心实验结果。

### 1.2 复现内容
- 搭建WSL2 + Conda的深度学习实验环境，对齐论文依赖版本
- 完成Unicorn Wget、StreamSpot两个批级检测数据集的加载与预处理
- 使用官方预训练模型权重，完成快速评估（Quick Evaluation）实验
- 输出AUC、F1、Precision、Recall等核心检测指标，与论文结果进行对比验证

## 二、论文与方法概述
### 2.1 研究背景
高级持续性威胁（APT）攻击具有隐蔽性强、攻击周期长、危害大的特点，传统基于规则的检测方法难以应对。溯源图（Provenance Graph）能够刻画系统实体与行为的依赖关系，是APT检测的重要数据载体。现有基于图的检测方法存在特征提取能力不足、难以应对概念漂移等问题。

### 2.2 MAGIC方法核心思路
MAGIC提出了基于掩码图表示学习的自监督APT检测框架，核心创新点包括：
1. 掩码图表示学习：通过自监督方式对溯源图进行特征提取与结构抽象，建模正常系统行为
2. 双粒度检测：同时支持批日志级（Batch-level）和系统实体级（Entity-level）两种检测粒度
3. 模型自适应机制：应对概念漂移问题，适配不同的检测场景与数据分布
4. 无监督异常检测：通过离群检测方法识别异常行为，无需大量标注攻击数据

## 四、实验数据集
本次复现覆盖论文中两个批级检测数据集，均使用官方预处理后的图数据缓存格式。
### 4.1 Unicorn Wget 数据集
- **数据类型**：批级溯源图数据集，包含正常与攻击的wget日志批次
- **数据规模**：共150张溯源图，其中125张良性、25张攻击
- **特征维度**：节点特征8维，边特征4维
- **检测任务**：判断单个日志批次是否为攻击批次
- **数据格式**：预处理后打包为`graphs.pkl`，直接加载使用

### 4.2 StreamSpot 数据集
- **数据类型**：批级溯源图数据集，包含多种正常与攻击场景的系统日志
- **数据规模**：共600张溯源图，其中400张良性、200张攻击
- **特征维度**：节点特征8维，边特征20维
- **检测任务**：判断单个日志批次是否为攻击批次
- **数据格式**：预处理后打包为`graphs.pkl`，直接加载使用

## 五、复现实验设计
### 5.1 实验模式
采用论文官方提供的Quick Evaluation（快速评估）模式：
- 使用作者训练完成的预训练模型权重（checkpoints目录下）
- 加载预处理好的图数据缓存文件
- 重复100次随机种子实验，输出平均结果与标准差
- 该模式对应论文中的模型性能验证场景，结果可直接与论文指标对比

### 5.2 评估指标
采用信息安全检测领域通用的核心指标：
1. AUC（Area Under Curve）：ROC曲线下面积，衡量模型整体检测能力，核心指标
2. F1值：精确率与召回率的调和平均，衡量综合分类性能
3. Precision（精确率）：预测为攻击的样本中真实攻击的比例
4. Recall（召回率）：真实攻击样本中被成功检测出的比例
5. 混淆矩阵：TN、FP、FN、TP，直观展示分类结果分布

## 七、复现过程中的问题与解决方案
### 7.1 代码文件语法错误问题
- **问题现象**：运行eval.py时报`SyntaxError: invalid syntax`，定位到`utils/loaddata.py`文件
- **问题原因**：前期手动修改代码时造成语法错误、缩进错误与导入缺失，且代码修改后影响pickle反序列化时的类匹配
- **解决方案**：清空原文件内容，粘贴官方原版完整代码，恢复与论文作者完全一致的代码逻辑，彻底解决语法错误与类定义问题

### 7.2 Pickle反序列化兼容问题
- **问题现象**：加载预处理`graphs.pkl`时出现连锁报错，涉及类找不到、对象不匹配
- **问题原因**：pickle序列化会绑定代码中的自定义类，代码修改后类定义变化会导致反序列化失败；不同DGL版本的图对象结构差异也会引发该问题
- **解决方案**：恢复原版代码后，官方预处理的pkl文件可正常加载；若版本不兼容，可删除pkl缓存，由代码自动从原始json重新生成适配当前环境的缓存文件

### 7.3 GitHub资源网络访问问题
- **问题现象**：使用curl下载官方原版代码文件时，报`Connection refused`，无法访问`raw.githubusercontent.com`
- **问题原因**：网络环境限制，无法直连GitHub原始文件域名
- **解决方案**：改用手动复制官方代码内容，通过nano编辑器粘贴覆盖本地文件，达到与在线下载相同的效果
